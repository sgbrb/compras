# 🛒 Lista de Compras + Controle de Gastos

Um app simples e funcional para organizar suas compras e acompanhar seus gastos.

## ✅ O que o app faz

- ✅ Criar múltiplas listas de compras
- ✅ Adicionar itens com nome e preço
- ✅ Marcar itens como "comprados"
- ✅ Ver total gasto por lista
- ✅ Aba "Gastos" com resumo mensal
- ✅ Compartilhar listas via código
- ✅ Funciona offline (dados salvos no celular)
- ✅ Design responsivo (funciona no celular e PC)

## 🚀 Como usar

1. Descompacte a pasta `lista-compras-app`
2. Abra o arquivo `index.html` no navegador (Chrome, Edge, Safari)
3. Pronto! O app já funciona

**Para usar no celular:**
- Abra no Chrome do celular
- Toque em "Adicionar à tela inicial"
- O app vira um app nativo!

## 📁 Arquivos

| Arquivo | Função |
|---------|--------|
| `index.html` | Estrutura das telas |
| `style.css` | Cores, fontes, layout |
| `app.js` | Toda a lógica do app |
| `manifest.json` | Configuração do PWA |
| `sw.js` | Funcionamento offline |

## 💡 Dicas

- Os dados ficam salvos no navegador (localStorage)
- Para limpar tudo: apague os dados do site no navegador
- Use o botão "Compartilhar" para enviar listas para outras pessoas
